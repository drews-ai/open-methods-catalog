# Open Methods Catalog

An open academic catalog of methodological code specimens and source-linked partials.

## Scope

This repository contains small public examples associated with a platform taxonomy. It is a reference and provenance surface, not the source repository for the platform website.

## Taxonomy

The directory structure follows **domain → activity → task → method**. Folder names use readable titles; catalog.json preserves the corresponding platform identifiers.

## Source-linking

Each specimen can be cited by an exact GitHub file and line range. Keep examples small, public, and clearly marked when illustrative.

## Exclusions

Do not commit secrets, credentials, private source, personal data, or production website code.
